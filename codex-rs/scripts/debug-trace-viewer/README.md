# Debug Trace Viewer

A standalone local viewer for canonical debug trace snapshots (`history.latest.json`).

This tool is designed for multi-agent debugging:

- Reads per-conversation snapshots from the trace root folder.
- Renders lane-based timelines by agent name.
- Groups events by second so parallel agent activity is visible side-by-side.
- Supports auto-refresh so the page updates while a task is running.

## Input Files

Expected layout (generated by Codex debug trace):

```text
<trace_root>/
  <conversation_id>/
    history.latest.json
    metadata.json
```

Default `trace_root` resolution:

1. `CODEX_DEBUG_TRACE_DIR` (if set)
2. `CODEX_HOME/debug/conversations` (if `CODEX_HOME` is set)
3. `~/.codex/debug/conversations`

## Run

From repository root:

```powershell
python scripts/debug-trace-viewer/server.py --open
```

Optional arguments:

```powershell
python scripts/debug-trace-viewer/server.py --root "C:\path\to\debug\conversations" --host 127.0.0.1 --port 8765 --open
```

Then open:

```text
http://127.0.0.1:8765
```

## API

- `GET /api/health`
- `GET /api/conversations`
- `GET /api/conversations/<conversation_id>/snapshot`

## Notes

- The viewer is read-only.
- Snapshot file is overwrite-on-update by design (`history.latest.json`), so reloading always reads the latest canonical state.
- For 4+ agents, the timeline table becomes horizontally scrollable to keep each lane readable.
